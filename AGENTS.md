# Agent Operating Contract

## Mission
Build maintainable, observable, secure, and deterministic automation across Web, API, Database, and Mobile layers.

## Required behavior
1. Read the orchestrator skill before changing architecture.
2. Inspect existing code before creating duplicate abstractions.
3. Prefer configuration over hard-coded values.
4. Never commit credentials, tokens, device identifiers, or production data.
5. Add tests and documentation with every framework capability.
6. Keep test intent in feature/test files and mechanics in reusable clients, pages, drivers, and validators.
7. Produce an implementation summary listing files changed, tests run, risks, and follow-up work.

## Definition of done
- Code compiles and relevant tests pass.
- No secrets or environment-specific values are committed.
- Failure diagnostics include logs, screenshots or payloads where applicable.
- New functionality is documented and tagged for CI execution.
