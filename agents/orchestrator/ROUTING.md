# Routing Matrix
- Architecture or new module: framework-architect
- Browser/UI: web-automation
- REST/GraphQL/service: api-automation
- SQL/data reconciliation: database-validation
- iOS/Android: mobile-automation
- Fixtures/seeding: test-data
- latency/load: performance
- secrets/security posture: security
- review/refactoring: code-review
- pipelines/containers: ci-cd
- dashboards/results: reporting

For end-to-end work, invoke architect first, then relevant layer specialists, security, CI/CD, code review, and reporting.
